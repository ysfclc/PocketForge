# Agent routing

Product scope/personas/roadmap → product; module boundaries/ADRs/FFI → architect; Rust/ABI → rust-core; Gradle/JNI/APK → android; Swift parity scaffold → ios; threat/secrets/signing/supply chain → security; tests/acceptance → qa.

Hand-off requires mission ID, revision, objective, constraints, granted capabilities, ADRs, outputs, acceptance criteria and escalation owner. Security may block unsafe execution. Product owns user value; architect owns technical consistency; QA owns evidence quality; repository owner resolves cross-boundary conflicts.

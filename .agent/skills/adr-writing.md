# Skill: adr-writing

## When to invoke
A consequential product, architecture, security or dependency choice is proposed.

## Preconditions
Owner, context and alternatives known.

## Exact procedure
State context; compare options including do-nothing; record choice, rejected alternatives, consequences, migration and revisit triggers.

## Verification
Reviewer can explain what was chosen and why.

## Failure modes
Missing owner/alternatives means Proposed, not Accepted.

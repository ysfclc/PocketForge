# iOS scaffold — gated, not built

This directory documents future Swift bridge parity only. No Xcode project, build, signing, provisioning or CI job is included.

Future Swift shell may use UniFFI or a C module map around the versioned C ABI. It must check ABI version and map stable error codes. Before implementation, approve macOS runner, minimum iOS version, signing/team ownership, distribution, privacy obligations and parity criteria in an ADR.

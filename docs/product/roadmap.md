# Roadmap

0. Keystone: contracts, Rust/Android/iOS scaffolds, agents, security, CI. Gate: actionlint, three Rust ABIs, debug APK, ZIP adversarial tests and provenance.
1. Local factory: import, workspace, Passport, local toolchain/build. Gate: two real projects build/install on target device; recovery and no data loss.
2. Intelligence Nexus: local model, frontier provider, capability router, durable mission and patch review. Gate: real bounded task delegated and approved.
3. Connectors: GitHub and Memo adapters. Gate: remote change reviewed and imported locally.
4. Production loop: diagnostics, tests, signing and artifact vault. Gate: reviewed agent change becomes tested signed APK; provenance verifies.
5. Expansion: more project types, agent collaboration, sync and iOS evaluation. Each requires demand evidence, ADR and reversible rollout.

# Personas

Primary — AI-assisted mobile builder: uses coding agents but struggles with Gradle, JDK, SDK/NDK and signing; wants an installable app rather than another chat/editor.

Secondary — solo builder: maintains several projects, values local control and cannot justify recurring cloud build costs.

Tertiary — agent power user: coordinates frontier models and automation tools and needs provider interchangeability, approvals and traceability.

Not initial targets: enterprise fleet/compliance teams, professional Android developers seeking Android Studio replacement, universal no-code consumers and iOS-first teams before the iOS gate.
